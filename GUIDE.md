# ПОДРОБНЫЙ ГАЙД ПО ЗАПУСКУ ПРОЕКТА

## Вариант А-24: Выпуклая оболочка

Этот файл содержит пошаговую инструкцию для запуска проекта на любом компьютере с нуля.

---

## ЧАСТЬ 1. Подготовка окружения

### Вариант А. Локальный запуск (графический интерфейс)

#### Шаг 1. Установите Python

1. Откройте браузер, перейдите на https://www.python.org/downloads/
2. Нажмите кнопку Download Python 3.12.x (или новее)
3. Запустите скачанный установщик
4. ВАЖНО: поставьте галочку Add Python to PATH внизу окна установщика
5. Нажмите Install Now
6. Дождитесь окончания установки (2-3 минуты)
7. Нажмите Close

Проверка установки:

- Нажмите Win + R
- Введите cmd и нажмите Enter
- Введите команду: python --version
- Должно появиться: Python 3.12.x

---

#### Шаг 2. Скачайте проект

Способ 1. Через Git (рекомендуется):

```
git clone https://github.com/<lkona666>/hull-practice.git
cd hull-practice
```

Способ 2. Через браузер:

1. Откройте репозиторий на GitHub
2. Нажмите зелёную кнопку Code
3. Выберите Download ZIP
4. Распакуйте архив в удобную папку
5. Откройте эту папку

---

#### Шаг 3. Запустите приложение

1. Откройте командную строку в папке проекта:
   - В проводнике кликните в адресную строку
   - Сотрите путь, напишите cmd
   - Нажмите Enter
2. Введите команду: python main.py
3. Откроется окно приложения

---

### Вариант Б. Запуск в Docker (консольная версия)

#### Шаг 1. Установите Docker Desktop

1. Перейдите на https://www.docker.com/products/docker-desktop/
2. Нажмите Download for Windows
3. Запустите установщик
4. Следуйте инструкциям (оставьте настройки по умолчанию)
5. Перезагрузите компьютер если потребуется
6. Запустите Docker Desktop
7. Дождитесь появления значка кита в трее (возле часов)

Проверка:

- Откройте командную строку
- Введите: docker --version
- Должно появиться: Docker version 24.x.x

---

#### Шаг 2. Соберите Docker-образ

1. Откройте командную строку в папке проекта
2. Выполните команду: docker build -t hull-app .

Что происходит:
- Docker скачивает образ Python 3.12
- Копирует ваши файлы в образ
- Создаёт образ с именем hull-app

Время сборки: 2-5 минут (первый раз)

---

#### Шаг 3. Запустите контейнер

Базовый запуск:

```
docker run --rm hull-app
```

Что происходит:
- Docker создаёт контейнер из образа hull-app
- Запускает консольную версию программы
- Выводит результат в терминал
- Удаляет контейнер после завершения (--rm)

---

## ЧАСТЬ 2. Работа с приложением

### Графический интерфейс

#### Добавление точек

Способ 1. Клик мышью:

1. Кликните в любом месте белого холста
2. Появится точка с координатами
3. Добавьте 10-15 точек

Способ 2. Загрузка из файла:

1. Нажмите кнопку Загрузить файл
2. Выберите data/sample.json
3. Появится 14 готовых точек

Способ 3. Пример данных:

1. Нажмите кнопку Пример данных
2. Автоматически загрузится набор точек

---

#### Построение оболочки

1. Алгоритм Грэхема: нажмите кнопку Грэхем. Справа появится информация: число вершин, количество операций, периметр, площадь
2. Алгоритм Джарвиса: нажмите кнопку Джарвис. Сравните число операций с Грэхемом
3. Сравнение: нажмите кнопку Сравнить оба. Увидите таблицу с результатами обоих алгоритмов

---

#### Анимация

1. Нажмите Анимация (Грэхем) или Анимация (Джарвис)
2. Наблюдайте пошаговое построение: точки подсвечиваются красным, показывается текущий шаг, внизу отображается описание действия

## ЧАСТЬ 4. Решение проблем

### Ошибка: python не является командой

Решение:
1. Переустановите Python
2. Обязательно поставьте галочку Add Python to PATH
3. Перезагрузите компьютер

---

### Ошибка: No module named tkinter

Решение:
1. Откройте Установка и удаление программ
2. Найдите Python 3.12
3. Нажмите Modify
4. Поставьте галочку tcl/tk and IDLE
5. Нажмите Update

---

### Ошибка Docker: Cannot connect to the Docker daemon

Решение:
1. Запустите Docker Desktop
2. Дождитесь появления зелёного значка кита
3. Попробуйте снова

---

### Ошибка: No such file or directory: data/sample.json

Решение:
1. Убедитесь, что вы в папке проекта
2. Проверьте, что папка data существует
3. Проверьте, что файл sample.json внутри
