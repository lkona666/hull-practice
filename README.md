## Описание

Проект реализует два классических алгоритма построения выпуклой оболочки множества точек на плоскости:

- **Сканирование Грэхема** (Graham's scan) — сложность O(n log n)
- **Обход Джарвиса** (Jarvis march / Gift wrapping) — сложность O(nh)

Функциональность:

- Графический интерфейс с пошаговой анимацией
- Ввод точек мышью или из файла (TXT, CSV, JSON)
- Вычисление периметра и площади оболочки
- Сравнение алгоритмов по числу операций
- Контейнеризация через Docker

## Установка и запуск

### Локально (графический интерфейс)

Требования: Python 3.12 или выше

Шаги:

1. Клонируйте репозиторий:

    git clone https://github.com/lkona666/hull-practice.git
    cd hull-practice

2. Запустите приложение:

    python main.py

3. Используйте интерфейс:
   - Кликайте по холсту для добавления точек
   - Или загрузите данные: кнопка «Загрузить файл» -> data/sample.json
   - Нажмите «Грэхем» или «Джарвис» для построения оболочки
   - Используйте «Анимация» для пошаговой визуализации

---

### В Docker (консольная версия)

Требования: Docker Desktop установлен

Шаги:

1. Соберите образ:

    docker build -t hull-app .

2. Запустите контейнер:

    docker run --rm hull-app

3. Или со своими данными:

    docker run --rm -v "$(pwd)/data:/app/data" hull-app data/sample.json

## Сравнение алгоритмов

| Алгоритм | Сложность | Преимущество |
|----------|-----------|--------------|
| Грэхем   | O(n log n) | Стабильно быстр при любом h |
| Джарвис  | O(nh)      | Быстр при малом h (h << log n) |

Вывод: Грэхем эффективнее в общем случае. Джарвис выгоден, когда число вершин оболочки мало.
