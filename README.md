# Визуализатор алгоритмов выпуклой оболочки — Учебная практика 2026

**Студент:** Медведев Даниил Владимирович  
**Группа:** БИН-24-1  
**Вариант:** А-24 — Выпуклая оболочка  
**Язык:** Python 3.12  
**Кафедра:** Информационных технологий и систем, ВВГУ

---

##  Описание

Проект реализует два классических алгоритма построения выпуклой оболочки множества точек на плоскости:
- **Сканирование Грэхема** (Graham's scan) — сложность O(n log n)
- **Обход Джарвиса** (Jarvis march / Gift wrapping) — сложность O(nh)

Приложение предоставляет:
- ✅ Графический интерфейс с пошаговой анимацией
- ✅ Ввод точек мышью или из файла (TXT, CSV, JSON)
- ✅ Вычисление периметра и площади оболочки
- ✅ Сравнение алгоритмов по числу операций
- ✅ Контейнеризацию через Docker

---

## 📁 Структура репозитория
hull/
├── main.py # Графический интерфейс (Tkinter)
── console_demo.py # Консольная версия для Docker
├── Dockerfile # Конфигурация Docker-контейнера
├── requirements.txt # Зависимости Python
├── README.md # Этот файл
├── GUIDE.md # Подробный гайд по запуску
└── data/
└── sample.json # Пример входных данных (14 точек)
